Moteur de rendu

Désactivé, le jeu dessine avec WebGL2 : le moteur sur lequel il a été conçu, qui fonctionne partout.

Activé, il essaie WebGPU, qui peut être plus fluide mais ne tient pas sur tous les navigateurs ni toutes les cartes graphiques. S’il cesse de fonctionner en jeu, il est désactivé et le jeu vous demande de recharger la page.

Développement

Pour construire les étapes suivantes du jeu sans y jouer. Désactivé, le jeu retrouve ses règles.

Raccourci pour saisir un code, en jeu : Ctrl + Alt + K (Échap pour fermer).

Ces paramètres s’appliquent aux nouvelles sessions de jeu.
